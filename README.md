# Panache Clothing Website

## Website purpose
Panache is a student-built clothing brand website presenting a streetwear collection under the motto **Style with Purpose**.

## Pages included
- `home.html` — brand introduction and featured products
- `shop.html` — tracksuits, T-shirts and tank tops with colour/size selection
- `cart.html` — cart items, quantity controls, remove controls and subtotal
- `checkout.html` — delivery form with browser validation (demonstration only)
- `aboutUs.html` — brand story, mission and vision
- `contact.html` — contact form with validation (demonstration only)
- `login.html` and `register.html` — account form layouts and validation
- `Policy.html` — privacy/website policy information
- `faq.html` — frequently asked questions

## Technologies used
HTML5, CSS3, and vanilla JavaScript. Cart contents are stored in the browser using `localStorage`. The shared stylesheet is `CSS/style.css`; shared JavaScript is `JS/script.js`; product images are in `images/`.

## Features
- Responsive product grid, header/navigation, forms and cart layout for desktop, tablet and mobile
- Visible keyboard focus states and native required-field/input validation
- Working add-to-cart buttons, cart quantity controls, remove controls and subtotal calculation
- Tracksuit colour selector updates to an image included with the project
- Meaningful image alt text

## How to run the website
1. Extract the ZIP while preserving the folder structure.
2. Open `Panache web/home.html` in a modern browser, or open the folder in Visual Studio Code and use a local server extension.
3. Shop products and visit the cart in the same browser to test localStorage behaviour.

## Important limitations
This is a front-end academic demonstration. It has no server/database, real account authentication, message delivery, inventory system, order submission or payment processing. Form success messages are demonstrations only. Never enter real payment-card information.
